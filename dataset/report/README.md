# Датасет результатов анализа безопасности

Датасет сформирован в рамках практической работы №1
по разработке безопасного программного обеспечения.

## Цель

Провести анализ сетевой точки входа с использованием нескольких
инструментов безопасности и сформировать единый структурированный
набор результатов.

## Исследуемая среда

Цель анализа: 10.200.1.2:8080.

Цель размещена в изолированном Linux network namespace и является
собственным учебным ресурсом.

На цели запущен HTTP-сервис Python SimpleHTTPServer.

## Использованные инструменты

- Git
- GitHub
- GitHub Meta API
- Nmap
- Masscan
- Nikto
- curl
- jq

## Структура

data/scan_findings.csv — нормализованный набор находок.

data/raw/ — оригинальные результаты работы сканеров.

meta/scan_findings.meta — описание датасета и условий исследования.

report/expert_assessment.md — экспертная оценка полученных результатов.

report/sources.md — используемые источники и инструменты.
