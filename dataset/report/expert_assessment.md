# Экспертная оценка безопасности

## 1. Область исследования

В рамках практической работы был проведён анализ сетевой точки входа
в изолированной учебной среде.

В качестве цели использовался собственный сетевой узел:

- IP-адрес: 10.200.1.2
- порт: 8080/TCP
- сервис: HTTP
- программное обеспечение: Python SimpleHTTPServer

Для формирования отдельной сетевой цели использовался Linux network
namespace, что позволило выполнять анализ без воздействия на сторонние
ресурсы.

Дополнительно через GitHub Meta API были получены публичные диапазоны
IP-адресов инфраструктуры GitHub. Эти диапазоны использовались только
для изучения и сохранения исходных данных и не подвергались
сканированию.

## 2. Результаты Nmap

Nmap обнаружил на узле 10.200.1.2 открытый TCP-порт 8080.

На данном порту определён HTTP-сервис:

SimpleHTTPServer 0.6 (Python 3.12.3)

Также стандартными NSE-скриптами Nmap было установлено:

- HTTP-заголовок сервера: SimpleHTTP/0.6 Python/3.12.3;
- корневая страница предоставляет Directory listing.

### Экспертная оценка

Наличие открытого порта само по себе не является уязвимостью, поскольку
порт был открыт намеренно в рамках лабораторного стенда.

Однако предоставление списка содержимого каталога может привести к
раскрытию файлов и структуры сервера. В реальной системе directory
listing рекомендуется отключать.

## 3. Результаты Masscan

Masscan независимо обнаружил:

8080/tcp open

на узле 10.200.1.2.

### Экспертная оценка

Результат Masscan подтверждает результат Nmap и показывает, что порт
доступен на сетевом уровне.

При эксплуатации реальной информационной системы рекомендуется
ограничивать количество доступных извне портов и оставлять только
необходимые сервисы.

## 4. Результаты Nikto

Nikto обнаружил следующие особенности конфигурации HTTP-сервиса:

1. Отсутствует заголовок X-Frame-Options.
2. SimpleHTTP/0.6 был отмечен сканером как потенциально устаревший.

### Отсутствие X-Frame-Options

Заголовок X-Frame-Options используется для ограничения возможности
отображения страницы внутри frame/iframe на сторонних сайтах.

Его отсутствие может увеличивать риск clickjacking для веб-приложений.

Экспертная оценка: низкий уровень риска для данного учебного сервера.
В реальном веб-приложении рекомендуется настроить защиту от
несанкционированного встраивания страниц.

### Информация о SimpleHTTP/0.6

Nikto отметил SimpleHTTP/0.6 как потенциально устаревший компонент.

Данная находка требует ручной проверки, так как строка
SimpleHTTP/0.6 является идентификатором встроенного HTTP-сервера Python
и не должна автоматически интерпретироваться как версия отдельного
установленного программного продукта.

Независимо от данной находки Python SimpleHTTPServer является
вспомогательным сервером разработки и не предназначен для использования
в качестве полноценного промышленного веб-сервера.

## 5. Общая экспертная оценка

В ходе анализа критические уязвимости обнаружены не были.

Сканеры подтвердили наличие одного доступного HTTP-сервиса на порту
8080 и выявили несколько особенностей его конфигурации.

Наиболее существенной находкой является включённый просмотр содержимого
каталога, поскольку при размещении конфиденциальных файлов это может
привести к раскрытию информации.

Результаты разных инструментов согласуются:

- Nmap обнаружил и идентифицировал HTTP-сервис;
- Masscan подтвердил доступность TCP-порта 8080;
- Nikto выполнил специализированную проверку HTTP-сервиса и выявил
  замечания к его конфигурации.

## 6. Рекомендации

1. Отключать directory listing на реальных веб-серверах.
2. Ограничивать доступ только к необходимым сетевым портам.
3. Настраивать защитные HTTP-заголовки.
4. Не использовать Python SimpleHTTPServer для промышленной эксплуатации.
5. Использовать актуальное серверное программное обеспечение.
6. Регулярно проводить повторное сканирование после изменения конфигурации.
7. Выполнять сетевое сканирование только в отношении собственных ресурсов
   или ресурсов, на тестирование которых получено разрешение.
